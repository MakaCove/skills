# 示例

下面示例只说明写法，不代表任何具体业务规则。

## 资料

需求：创建记录时名称必填，名称最多 20 个字符；保存成功后列表显示新记录。

原型：新增弹窗包含名称输入框和保存按钮；名称为空时显示必填提示。

代码：前端提交 `name`；后端校验空值和长度；保存成功后返回新记录编号，前端刷新列表。
