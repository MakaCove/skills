# 功能测试用例技能说明

本技能只负责根据需求文档、原型图、前端代码和后端代码生成一份功能测试用例文件。

数据库连接 MCP 可由用户手动提供，也可以不提供。没有数据库 MCP 时仍然继续生成用例，无法确认的数据库检查点写入 Excel 的“信息缺口”工作表。

不要求用户提供用户角色说明、测试账号、接口文档、接口日志或运行日志。接口和参数信息从前后端代码中提取；资料没有明确说明的内容不自行编造。

最终只交付一个文件：`功能测试用例.xlsx`。

## 目录

| 路径 | 内容 |
|------|------|
| `SKILL.md` | 执行规则、分析流程、覆盖范围和输出约束 |
| `references/材料抽取.md` | 需求、原型和代码的抽取方法 |
| `references/测试方法.md` | 八大测试用例设计方法 |
| `references/判定.md` | 方法适用、用例合并和覆盖完成的判定规则 |
| `references/覆盖合同.md` | 需求、页面、接口和代码分支的覆盖追踪 |
| `references/用例格式.md` | Excel 工作表和测试用例字段 |
| `references/示例.md` | 测试用例示例 |
| `references/输出与脚本.md` | 单文件交付和内部脚本说明 |
| `scripts/` | 可选的扫描、校验和 Excel 导出脚本 |

前端目录、后端目录或输出目录未指定时，读取 `config/projects.json`。如果数据库 MCP 不可用，不重复要求用户提供。
