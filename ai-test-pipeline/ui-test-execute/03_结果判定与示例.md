# 结果判定与示例（UI）

## 背景

演示 UI 执行器如何判定用例结果、截图并生成报告。

## 输入

- 用例文件：`ai-tests/test-artifacts/ui-cases/ui-cases-{ts}.json`
- 执行命令：`node ai-tests/scripts/run-ui-tests.mjs`

## 判定逻辑

| 状态 | 条件 |
|------|------|
| `passed` | 步骤全部成功且断言全部通过 |
| `failed` | 步骤失败或断言失败 |
| `skipped` | 上游失败或变量缺失 |

## 输出

- `ai-tests/test-artifacts/ui-reports/ui-report-{ts}.md`
- `ai-tests/test-artifacts/ui-reports/screenshots/*`
- 每条用例明细下方嵌入对应截图（Markdown 图片）

## 关键字段说明

| 报告章节 | 内容 |
|----------|------|
| 概览 | 通过/失败/跳过/通过率 |
| 覆盖统计 | 来自 `meta.coverage` |
| 失败/跳过用例 | 明细 + **截图（紧跟其后）** |
| 全部用例明细 | 表格摘要 |
| 用例明细与截图 | 全量用例明细，每条下方嵌入截图 |

## 验收点

- [ ] 失败用例自动截图
- [ ] `click_menu` 步骤使用 `routeMenuMap` 映射
- [ ] 报告路径正确写入 `ui-reports/`

UI 断言类型见 [shared/06_断言语法.md](../shared/06_断言语法.md)。

完整用例示例见 [ui-test-case-generate/04_完整示例.md](../ui-test-case-generate/04_完整示例.md)。
