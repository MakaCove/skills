# 浏览器配置

UI 执行器支持自动选择固定 Chromium 或系统 Chrome。

## 默认模式：有头（headed）+ 窗口最大化

- `defaultProfile: "auto-headed"`，`headed: true`
- 有头模式**默认最大化**：`launchOptions.args` 含 `--start-maximized`，`contextOptions.viewport: null`
- 执行器在脚本层也会强制注入上述设置（即使用户配置遗漏）
- 只有显式加 `--headless` 才会改为无头

## 配置文件

- 实际配置（执行器读取）：[ai-tests/test-artifacts/ui-test.config.json](../../test-artifacts/ui-test.config.json)
- 字段说明：[shared/09_ui-test-profile模板.md](../shared/09_ui-test-profile模板.md)

## 常用命令

```bash
# 有头（默认）
node ai-tests/scripts/run-ui-tests.mjs --limit 20
node ai-tests/scripts/run-ui-tests.mjs --local-chrome --limit 20

# 无头（须显式指定）
node ai-tests/scripts/run-ui-tests.mjs --headless --all
```
