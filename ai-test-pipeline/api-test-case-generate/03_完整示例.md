# 完整示例

## 背景

演示 API 主流程用例如何从登录到创建订单、提交审核，形成完整链路。

## 输入

后端主流程：

- `POST /api/v1/auth/login` → token
- `POST /api/v1/orders` → orderId（body 需 `customerId`）
- `PUT /api/v1/orders/{id}/submit` → 提交审核

`CreateOrderDTO` 含 `customerId`、`sku`、`quantity`。

识别的主流程：

| id | name | suggestedCaseIds |
|----|------|------------------|
| FLOW-AUTH-001 | 登录获取 token | TC-API-AUTH-001 |
| FLOW-ORDERS-001 | 创建并提交订单 | TC-API-ORDERS-001, TC-API-ORDERS-002 |
