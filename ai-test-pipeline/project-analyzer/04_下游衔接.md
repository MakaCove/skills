# 下游衔接

`project-analysis` 产物会被两个生成阶段消费：

- `api-test-case-generate`
- `ui-test-case-generate`

## 衔接规则

- `mainFlowCandidates` → 下游确认为 `mainFlowInventory`
- `stateHints` → 下游补足状态流转型主流程
- `navigationTree` → UI 用例的完整菜单导航路径（层级 + 功能入口）
- `pageEntryHints` → UI 用例的单页 DOM 拆解补充（弹窗/表单/表格）
- `auth` → API/UI 执行时的会话信息
