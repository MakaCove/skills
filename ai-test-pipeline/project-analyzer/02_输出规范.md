# 输出规范

`project-analyzer` 的输出文件为：

- `ai-tests/test-artifacts/project-analysis-{ts}.json`
- schema：`ai-test-pipeline/project-analysis/v2`

## 必填字段

- `schema`
- `generatedAt`
- `project`
- `auth`
- `scanLimitations`
- `mainFlowCandidates`
- `modules`
- `summary`

## 推荐字段

- `chainHints`
- `stateHints`
- `navigationTree`
- `pageEntryHints`
- `downstream`

## 输出要求

- `scanLimitations` 必须如实填写
- `mainFlowCandidates` 至少覆盖核心业务主链路
- `auth` 信息从代码或配置中识别，不写死默认值
- `navigationTree` 与 `pageEntryHints` 从布局组件源码提取，不得猜测

Canonical Schema 见 [shared/03_项目分析结构.md](../shared/03_项目分析结构.md)。
