# 多栈扫描指南

> 按项目**实际技术栈**选用对应模式；可同时存在多种入口（如 Spring + 独立 BFF）。

## 后端 API 入口

| 栈 | 典型 Glob | 提取方式 |
|----|-----------|----------|
| **Java Spring MVC** | `**/*Controller.java` | `@RestController` + `@RequestMapping` 前缀；方法上 `@GetMapping` 等 |
| **Kotlin Spring** | `**/*Controller.kt` | 同上 |
| **Go (Gin/Echo/Chi)** | `**/handler*.go`、`**/*_handler.go`、`**/routes.go` | `router.GET/POST`、`Group()` 前缀 |
| **Node NestJS** | `**/*.controller.ts` | `@Controller()` + `@Get/@Post` |
| **Python FastAPI** | `**/routers/*.py`、`**/api/*.py` | `@router.get/post`、APIRouter prefix |
| **Python Flask/Django REST** | `**/views.py`、`**/urls.py` | 路由注册 + View 类 |
| **OpenAPI 优先** | `**/openapi.yaml`、`**/swagger.json` | 作为端点清单补充，**仍须与代码交叉验证** |

### 路径拼接规则

1. 类/模块级 prefix + 方法级 path → 完整 path
2. 路径变量统一为 `{id}` 形式（Spring `{id}`、FastAPI `{item_id}` 保留原名亦可，但全文一致）
3. `apiPrefix` 写入 `project.backend.apiPrefix`，端点 path 写**完整路径**

### 鉴权识别（勿写死 JWT）

| 信号 | 可能的 auth.type |
|------|------------------|
| `Authorization: Bearer` + JWT 库 | `JWT Bearer Token` |
| 内存 Map / UUID token、非 JWT 解析 | `Bearer Token（非 JWT，如会话 UUID）` |
| `JSESSIONID` / `@SessionAttribute` | `Session Cookie` |
| `X-API-Key` header | `API Key` |
| Spring Security `permitAll` / 拦截器白名单 | 写入 `auth.publicEndpoints` |
| 无全局鉴权 | `none` 或 `endpoint-level` |

**测试账号**：仅从 README、`.env.example`、`application.yml`、种子数据脚本中读取；找不到则 `testAccount: null` 并注明。

## 前端路由

| 栈 | 典型 Glob | 提取方式 |
|----|-----------|----------|
| **Vue 3 + Vue Router** | `**/router/index.ts`、`**/router/*.ts` | `routes[]`：path、name、component、meta |
| **React Router v6** | `**/App.tsx`、`**/routes.tsx` | `<Route path=`、`createBrowserRouter` |
| **Next.js App Router** | `**/app/**/page.tsx` | 目录结构 → URL |
| **Next.js Pages** | `**/pages/**/*.tsx` | 文件路径 → URL |
| **Angular** | `**/*-routing.module.ts` | `RouterModule.forRoot` |

### 页面 summary 写法

打开 `component` 指向的 `.vue`/`.tsx`，用 1 句话描述**用户可见的主要能力**，例如：

- ✅ `项目列表页（搜索、分页、新增弹窗、行内编辑/删除）`
- ❌ `项目管理页面`（过泛，未读源码）

## 模块划分（通用启发式）

按 URL 第一段或 Controller 包名分组，**名称取自代码**：

```
/api/v1/auth/*     → auth
/api/v1/orders/*   → orders
/views/OrderList   → orders（前端路由对齐）
```

优先级（P0/P1/P2）依据：

- P0：登录、核心业务 CRUD、支付/审批等主流程
- P1：配置、统计、个人中心
- P2/P3：辅助、调试、仅管理员

**禁止**复制示例中的 `projects/assets/testcases` 等模块名到无关项目。
