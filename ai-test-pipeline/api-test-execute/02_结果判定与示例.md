# 结果判定与示例（API）

## 背景

演示 API 执行器如何判定用例结果并生成报告。

## 输入

- 用例文件：`ai-tests/test-artifacts/api-cases/api-cases-{ts}.json`
- 执行命令：`node ai-tests/scripts/run-api-tests.mjs`

## 判定逻辑

| 状态 | 条件 |
|------|------|
| `passed` | 全部断言通过 |
| `failed` | 任一断言失败或请求异常 |
| `skipped` | 上游失败或变量缺失 |

## 输出

- `ai-tests/test-artifacts/api-reports/api-report-{ts}.md`
- 含覆盖统计、失败明细、全量执行明细
- **每条用例含入参（请求）与响应体**

## 关键字段说明

| 报告章节 | 内容 |
|----------|------|
| 概览 | 通过/失败/跳过/通过率 |
| 覆盖统计 | 来自 `meta.coverage` |
| 失败/跳过用例 | 含错误信息、**请求入参**、**响应** |
| 全部用例明细 | 逐条执行结果摘要 |
| 用例请求与响应明细 | 全量用例的 method/url/headers/body 与响应 |

## 验收点

- [ ] 报告路径正确写入 `api-reports/`
- [ ] 失败用例包含字段级错误定位
- [ ] 覆盖率统计与用例 meta 一致

断言算子见 [shared/06_断言语法.md](../shared/06_断言语法.md)。
