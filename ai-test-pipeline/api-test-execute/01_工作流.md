# 工作流（API 执行）

0. 确保执行脚本就绪 — 检查目标项目 `ai-tests/` 目录（见下方「步骤 0」）
1. 确认测试地址：用例 `meta.baseUrl` 或执行参数 `--base-url`（由用户提供，技能包不写死）
2. 运行校验：`node ai-tests/scripts/validate-artifacts.mjs --type api`
3. 运行执行器：`node ai-tests/scripts/run-api-tests.mjs`（或 `--base-url <地址>`）
4. 查看报告：`ai-tests/test-artifacts/api-reports/`

## 步骤 0：确保执行脚本就绪

执行 API 测试前，先确保目标项目根目录下存在所需脚本：

1. 定位目标项目根目录：`ai-tests/` 所在目录（通常即当前工作目录）
2. 若 `ai-tests/scripts/` 目录不存在，创建它
3. 检查并按需复制（文件已存在则跳过，保护项目定制修改）：
   - `ai-tests/scripts/validate-artifacts.mjs` ← 从技能包 `scripts/` 复制（校验脚本，UI/API 共用）
   - `ai-tests/scripts/run-api-tests.mjs` ← 从技能包 `scripts/` 复制（API 执行器）
4. 输出摘要：哪些已存在（跳过）、哪些刚复制

## 测试地址

- 来源优先级：`--base-url` > 用例 `meta.baseUrl`
- 无需事先确认服务是否启动；执行器直接请求给定地址，失败在用例/报告中体现

## 失败处理

- 字段错误：修正 JSON 结构
- 依赖错误：检查 `trace.dependsOn`
- 变量错误：检查 `trace.consumes/produces` 与 `extract`
