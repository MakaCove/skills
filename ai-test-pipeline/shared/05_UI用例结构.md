# UI 用例结构

> **schema**：`ai-test-pipeline/ui-case/v2`

UI 用例文件是一个 **JSON 数组**：第一个元素为**元信息**（含 `coverage.mainFlowInventory`），其余为**用例对象**。

## 单条用例字段速查

| 分组 | 字段 | 必填 | 说明 |
|------|------|------|------|
| **基本信息** | `id` | ✅ | `TC-UI-{模块}-{编号}`，文件内唯一 |
| | `title` | ✅ | 中文简短描述 |
| | `module` | ✅ | 小写英文模块名 |
| | `priority` | ✅ | P0/P1/P2/P3 |
| **追溯链路** | `trace.flowRefs` | ✅ | 主流程 id 数组（`FLOW-*`） |
| | `trace.dependsOn` | 条件 | 上游用例 id 数组 |
| | `trace.produces` | 条件 | 本用例产出的变量名 |
| | `trace.consumes` | 条件 | 本用例消费的变量名 |
| **步骤** | `steps` | ✅ | 有序操作步骤（见 action 表） |
| **断言** | `assertions` | ✅ | UI 断言（见 `断言语法.md`） |
| **清理** | `teardown` | 否 | 清理步骤 |

## 文件结构

```json
[
  {
    "schema": "ai-test-pipeline/ui-case/v2",
    "generatedAt": "2026-05-29T10:00:00+08:00",
    "baseUrl": "http://localhost:5173",
    "navigationModel": "menu-driven",
    "sourceAnalysis": "ai-tests/test-artifacts/project-analysis-20260529-095500.json",
    "totalCases": 2,
    "coverage": {
      "mainFlowTotal": 2,
      "mainFlowsCovered": 2,
      "mainFlowCoveragePercent": 100,
      "uncoveredMainFlows": [],
      "orphanCases": 0,
      "routeMenuMap": [],
      "mainFlowInventory": []
    }
  },
  { "id": "TC-UI-ORDERS-001", "trace": { "flowRefs": ["FLOW-ORDERS-001"] }, "..." : "..." }
]
```

## 元信息（首元素）

| 字段 | 必填 | 说明 |
|------|------|------|
| `schema` | ✅ | 固定 `ai-test-pipeline/ui-case/v2` |
| `generatedAt` | ✅ | ISO 8601 时间 |
| `baseUrl` | ✅ | 前端测试地址（用户提供或从 project-analysis 读取，必填） |
| `navigationModel` | ✅ | 固定 `menu-driven`；步骤按菜单路径编排 |
| `sourceAnalysis` | 推荐 | 引用的 project-analysis 文件路径 |
| `totalCases` | ✅ | 实际用例数（**结果值，非 KPI**） |
| `coverage` | ✅ | 覆盖统计与主流程清单 |

### coverage 字段

| 字段 | 说明 |
|------|------|
| `mainFlowTotal` / `mainFlowsCovered` / `mainFlowCoveragePercent` | **业务主流程**覆盖率，验收目标 **100%** |
| `uncoveredMainFlows` | 未覆盖主流程 id，应为 `[]` |
| `mainFlowInventory` | 主流程清单（见下文） |
| `routeMenuMap` | 路由与侧栏菜单文案映射（menu-driven 必填） |
| `orphanCases` | 无 `trace.flowRefs` 的用例数，应为 **0** |
| `flowChains` | 可选：上下游链路覆盖统计 |

### routeMenuMap[]（menu-driven 必填）

```json
{
  "route": "/projects",
  "menuLabel": "项目管理",
  "menuGroup": "资产管理",
  "requiresAuth": true
}
```

无侧栏页面（如 `/login`）：`menuLabel: null`，可附 `navigation: { "type": "direct" }`。

## mainFlowInventory[]（主流程清单）

```json
{
  "id": "FLOW-ORDERS-001",
  "name": "创建订单并在列表可见",
  "module": "orders",
  "priority": "P0",
  "userGoal": "业务用户新建订单并在列表中看到",
  "menuPath": ["订单管理"],
  "stepsSummary": "菜单进入 → 新建 → 填表提交 → 列表可见",
  "evidence": ["OrdersView.vue: 新建订单按钮"],
  "suggestedCaseIds": ["TC-UI-ORDERS-001"],
  "chainVars": ["orderTitle"],
  "confidence": "high"
}
```

用例通过 `trace.flowRefs: ["FLOW-ORDERS-001"]` 追溯。

## 用例对象

```json
{
  "id": "TC-UI-ORDERS-001",
  "title": "创建订单并在列表可见",
  "module": "orders",
  "priority": "P0",
  "trace": {
    "flowRefs": ["FLOW-ORDERS-001"],
    "dependsOn": ["TC-UI-AUTH-001"],
    "produces": ["orderTitle"],
    "consumes": ["sessionUser"]
  },
  "steps": [
    { "step": 1, "action": "ensure_session" },
    { "step": 2, "action": "click_menu", "target": "订单管理" },
    { "step": 3, "action": "wait", "value": "1000" },
    { "step": 4, "action": "click", "target": "新建订单" },
    { "step": 5, "action": "fill", "target": "订单标题", "value": "AUTO-{{timestamp}}", "saveAs": "orderTitle" },
    { "step": 6, "action": "click", "target": "提交" },
    { "step": 7, "action": "wait", "value": "1500" }
  ],
  "assertions": [
    { "type": "url_contains", "target": "/orders", "expected": true },
    { "type": "text_contains", "target": "AUTO-", "expected": true }
  ]

```

## ID 命名（统一规则）

| 类型 | 格式 | 示例 |
|------|------|------|
| 主流程 | `FLOW-{MODULE}-{序号}` | `FLOW-ORDERS-001` |
| 用例 | `TC-UI-{MODULE}-{序号}` | `TC-UI-ORDERS-001`、`TC-UI-AUTH-001` |

### steps[].action

**会话与导航**：

| action | target | 说明 |
|--------|--------|------|
| `reset_session` | — | 清除登录态 |
| `open_login` | — | 打开登录页 |
| `ensure_session` | — | 确保已登录 |
| `click_menu` | 侧栏菜单文案 | 进入业务页面 |
| `navigate` | 路由 path | **仅**路由守卫/深链专项 |

**功能操作**：`click` | `fill` | `select` | `hover` | `wait` | `press_key` | `screenshot` | `scroll`

| 子字段 | 说明 |
|--------|------|
| `step` | 序号，从 1 开始 |
| `target` | 元素描述 |
| `value` | 输入值、等待毫秒 |
| `saveAs` | 将步骤产出保存为变量 |
| `useVar` | 声明步骤消费的变量 |

## 验收要点

- [ ] 每条主流程的 `suggestedCaseIds` 均有对应用例
- [ ] `orphanCases === 0`
- [ ] 所有 `trace.flowRefs` 可在 `mainFlowInventory` 中找到
- [ ] 业务页经 `click_menu` 进入（守卫专项除外）
- [ ] 不以 `totalCases` 与路由数比较论「达标/未达标」
