# 断言语法

接口测试和 UI 测试共用一套断言语法规范。

## 接口断言

每条断言是一个 JSON 对象：

```json
{
  "field": "status",
  "operator": "eq",
  "expected": 200
}
```

### 操作符

| 操作符 | 含义 | 示例 |
|--------|------|------|
| `eq` | 等于 | `"status": 200` |
| `neq` | 不等于 | `"status": 403` |
| `contains` | 响应体/字段包含指定字符串 | `"body": "token"` |
| `not_contains` | 响应体/字段不包含指定字符串 | `"body": "error"` |
| `gt` | 大于 | `"body.data.total": 0` |
| `lt` | 小于 | `"body.data.total": 100` |
| `exists` | 字段存在且不为 null | `"body.data.id"` |
| `regex` | 匹配正则表达式 | `"body.token": "^[A-Za-z0-9-_]+\\.[A-Za-z0-9-_]+\\.[A-Za-z0-9-_]*$"` |
| `type` | 类型匹配（`string`/`number`/`boolean`/`object`/`array`/`null`） | `"body.data.list": "array"` |

### 字段路径

使用点号访问嵌套 JSON：`body.data.items[0].name`。

### `type` 判定说明

- `array`：使用 `Array.isArray(实际值)` 判定。
- `null`：判定 `实际值 === null`。
- 其它类型按 JavaScript `typeof` 判定（如 `string`、`number`、`boolean`、`object`）。

## UI 断言

每条 UI 断言均为：

```json
{
  "type": "<断言类型>",
  "target": "<定位线索>",
  "expected": true
}
```

### 元素可见性

| 类型 | 含义 | `expected` 语义 |
|------|------|-----------------|
| `element_visible` | 元素可见 | `true` 预期可见 / `false` 预期不可见 |
| `element_hidden` | 元素不可见 | 忽略 `expected`（始终判定为不可见） |
| `element_disabled` | 元素禁用态 | `true` 预期禁用 / `false` 预期不禁用 |
| `element_enabled` | 元素可用态 | `true` 预期可用 / `false` 预期不可用 |

### 文本 / 页面内容

| 类型 | 含义 | 说明 |
|------|------|------|
| `text_contains` | 页面 HTML 包含指定文本 | `target` 必须出现在 `page.content()` 中 |
| `text_not_contains` | 页面 HTML 不包含指定文本 | 与 `text_contains` 取反 |
| `toast_contains` | 页面 HTML 包含 toast 提示文本 | **实现同 `text_contains`，均为 `page.content()` 全文匹配** |
| `toast_not_contains` | 页面 HTML 不包含 toast 提示文本 | 实现同 `text_not_contains` |

> **注意**：`toast_contains` / `toast_not_contains` 不专门查找 toast 组件；它们与 `text_contains` 语义相同，仅为用例可读性而存在别名。

### URL

| 类型 | 含义 |
|------|------|
| `url_equals` | 当前 URL 完全匹配（末尾 `/` 忽略） |
| `url_contains` | 当前 URL 包含指定字符串 |

### 数量

| 类型 | 含义 |
|------|------|
| `count_gte` | 匹配元素数量 >= `expected` |
| `count_gt` | 匹配元素数量 > `expected` |
| `count_eq` | 匹配元素数量 == `expected` |
| `count_lt` | 匹配元素数量 < `expected` |
| `count_lte` | 匹配元素数量 <= `expected` |

### 输入框 / 弹窗 / 属性

| 类型 | 含义 | 说明 |
|------|------|------|
| `input_value_equals` | 输入框当前值等于 `expected` | `target` 定位到 `input`/`textarea`，读取并比对 `inputValue()` |
| `input_value_contains` | 输入框当前值包含 `expected` | 同上，用 `includes()` |
| `dialog_visible` | 页面上存在可见弹窗/抽屉 | 通过 `visibleDialogRoot` 查找 `.el-dialog:visible` / `[role="dialog"]:visible` / `.el-overlay .el-dialog__wrapper:visible` / `.el-overlay .el-drawer__wrapper:visible`。若 `target` 非空，则进一步校验弹窗内包含 `target` 文本 |
| `dialog_hidden` | 页面上不存在可见弹窗/抽屉 | 返回 `visibleDialogRoot` 为 null 即通过 |
| `attribute_equals` | 元素指定属性值等于 `expected` | 需额外字段 `attrName`（如 `"attrName": "disabled"`） |

### 示例

```json
// element_disabled — 提交按钮置灰
{ "type": "element_disabled", "target": "提交", "expected": true }

// element_enabled — 提交按钮可点击
{ "type": "element_enabled", "target": "提交", "expected": true }

// input_value_equals — 验证输入框当前值
{ "type": "input_value_equals", "target": "订单标题", "expected": "AUTO-20260609" }

// count_gt — 验证至少有 N 条记录
{ "type": "count_gt", "target": "role=row", "expected": 1 }

// dialog_visible — 弹窗仍打开（如校验失败后弹窗不关闭）
{ "type": "dialog_visible", "target": "dialog:新建订单|提交", "expected": true }

// dialog_hidden — 弹窗已关闭（如取消操作后）
{ "type": "dialog_hidden", "expected": true }

// toast_contains — 创建成功提示出现
{ "type": "toast_contains", "target": "创建成功", "expected": true }

// attribute_equals — 验证元素属性
{ "type": "attribute_equals", "target": "提交", "attrName": "disabled", "expected": "true" }
```
