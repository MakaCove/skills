# 选择器策略

`locateInRoot` 按以下顺序查找目标元素，**先匹配者胜出**（即优先级从高到低）：

| 层 | 匹配 | target 格式 | 说明 |
|----|------|-------------|------|
| 1 | CSS 直传 | `#id` / `.class` / 任意 CSS selector | 绕过文案匹配，直接使用 Playwright CSS selector |
| 2 | 文本框序号 | `textbox:0` / `textbox:1` | 按序号取当前 scope 内的 `<input type="text">` |
| 3 | 密码框序号 | `password:0` / `password:1` | 按序号取当前 scope 内的 `<input type="password">` |
| 4 | 工具栏按钮 | `toolbar:<文案>` | 匹配 `.buttonItem .table_list_btn` / `.el-button--primary` 中精确匹配文案的按钮 |
| 5 | 弹窗底部按钮 | `footer:primary` / `footer:cancel` / `footer:<文案>` | 匹配 `.dialog-footer` / `.el-dialog__footer` 中的按钮；若含"确"则退化为 footer:primary，含"取"则退化为 footer:cancel |
| 6 | 弹窗确定/取消 | `确定` / `取消` | 精确匹配 dialog footer 中的按钮文案 |
| 7 | 输入组附加按钮 | `append-btn:<label>` | 匹配 `.el-form-item` 中 label 对应的 `.el-input-group__append .el-button` |
| 8 | 表格行操作 | `row-action:<文案>` | 匹配 `.vxe-body--row` 第一行的操作按钮 |
| 9 | 表格行序号 | `row:0` / `row:1` / `第一行` | 匹配 `.vxe-body--row` 第 N 行的 checkbox（有则优先）或整行 |
| 10 | 下拉框序号 | `select:0` / `select:1` | 匹配第 N 个 `.el-select` 组件 |
| 11 | 登录字段 | `账号` / `密码` | 匹配 `#formLogin` / `.user-layout-login` 内对应字段 |
| 12 | data-testid | `testid=<value>` | `getByTestId` |
| 13 | ARIA role | `role=<role>\|<name>` | `getByRole`（name 为完全文案） |
| 14 | el-form-item label | 普通文案 | 匹配 `.el-form-item` 中 label （正则全匹配）后取内部 `.el-input input, .el-select input, .el-textarea textarea` |
| 15 | 通用 role 枚举 | 普通文案 | 依次查找 `button` / `link` / `menuitem` / `tab` / `checkbox` |
| 16 | label | 普通文案 | `getByLabel`（exact: false） |
| 17 | placeholder | 普通文案 | `getByPlaceholder`（exact: false） |
| 18 | text 兜底 | 普通文案 | `getByText`（exact: false） |

**建议**：在用例中优先给出 `testid=<xxx>` 或 CSS selector，降低文案变更带来的定位波动。
