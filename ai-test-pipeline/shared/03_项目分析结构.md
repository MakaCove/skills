# 项目分析结构

> **schema**：`ai-test-pipeline/project-analysis/v2`

`project-analysis-*.json` 是流水线**第一步**产物：端点/路由/模块**索引地图** + 主流程候选预标注。

## 顶层结构

```json
{
  "schema": "ai-test-pipeline/project-analysis/v2",
  "generatedAt": "2026-05-29T15:00:00+08:00",
  "project": { },
  "auth": { },
  "scanLimitations": [],
  "chainHints": { },
  "stateHints": [],
  "mainFlowCandidates": [],
  "navigationTree": [],
  "pageEntryHints": [],
  "downstream": { },
  "modules": [],
  "summary": { }
}
```

## project

| 字段 | 必填 | 说明 |
|------|------|------|
| `name` | ✅ | 项目名称 |
| `type` | ✅ | `前后端分离` \| `全栈单体` \| `纯后端` \| `纯前端` |
| `backend.language` | 条件 | 实际栈描述，**勿写死** Spring |
| `backend.baseUrl` | ✅ | 从项目配置/用户输入读取，勿写死 |
| `backend.apiPrefix` | 推荐 | 如 `/api/v1` |
| `frontend.framework` | 条件 | 实际栈描述 |
| `frontend.baseUrl` | 条件 | 从项目配置/用户输入读取，勿写死 |

## auth

| 字段 | 必填 | 说明 |
|------|------|------|
| `type` | ✅ | **从代码识别**：JWT Bearer、Session Cookie、`none` 等 |
| `loginEndpoint` | 推荐 | `{ method, path }` |
| `tokenHeader` | 推荐 | 如 `Authorization` |
| `tokenFormat` | 推荐 | 如 `Bearer {token}` |
| `publicEndpoints` | 推荐 | 匿名/白名单路径数组 |
| `testAccount` | 推荐 | `{ username, password }`；找不到则 `null` |

## scanLimitations（必填）

本阶段**未覆盖**的内容，防止下游误把 analysis 当完整契约。

## chainHints（推荐）

用于向下游提供"可串联场景"的线索。

```json
{
  "enabled": true,
  "candidateChains": [
    {
      "id": "CH-ORDERS-LIFECYCLE",
      "module": "orders",
      "type": "resource-lifecycle",
      "producerEndpoints": ["POST /api/v1/orders"],
      "consumerEndpoints": ["GET /api/v1/orders/{id}", "PUT /api/v1/orders/{id}", "DELETE /api/v1/orders/{id}"],
      "suggestedVars": ["orderId"],
      "confidence": "high"
    }
  ],
  "crossModuleRefs": [
    {
      "from": { "module": "versions", "dto": "CreateVersionDTO", "field": "projectId" },
      "to": { "module": "projects", "dto": "ProjectDTO", "field": "id" },
      "evidence": "CreateVersionDTO.projectId 引用 ProjectController.create 产出的 id"
    }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `candidateChains[].type` | `resource-lifecycle` / `auth-context` / `state-transition` / `workflow` |
| `producerEndpoints[]` | 产出型端点 |
| `consumerEndpoints[]` | 消费型端点 |
| `suggestedVars[]` | 推荐变量名 |
| `confidence` | `high` / `medium` / `low` |
| `crossModuleRefs[]` | 跨模块外键依赖（含 DTO 字段级证据） |

## stateHints[]（推荐 · 新增）

状态机线索，消除状态流转类主流程遗漏：

```json
[
  {
    "resource": "order",
    "module": "orders",
    "statusField": "status",
    "states": ["DRAFT", "SUBMITTED", "APPROVED", "PUBLISHED"],
    "transitions": [
      { "from": "DRAFT", "to": "SUBMITTED", "endpoint": "PUT /api/v1/orders/{id}/submit", "evidence": "OrderController.submit" },
      { "from": "SUBMITTED", "to": "APPROVED", "endpoint": "PUT /api/v1/orders/{id}/approve", "evidence": "OrderController.approve" }
    ]
  }
]
```

扫描来源：DTO/Entity 中的 `status`/`state` 枚举字段、Controller 中状态推进端点。

## mainFlowCandidates[]（推荐 · 新增）

主流程候选预标注，下游生成技能逐条确认/扩展/排除：

```json
[
  {
    "id": "CANDIDATE-ORDERS-001",
    "module": "orders",
    "name": "订单创建",
    "type": "resource-lifecycle",
    "endpoints": ["POST /api/v1/orders"],
    "confidence": "high",
    "source": "chainHints + Controller"
  },
  {
    "id": "CANDIDATE-ORDERS-002",
    "module": "orders",
    "name": "订单提交审核",
    "type": "state-transition",
    "endpoints": ["PUT /api/v1/orders/{id}/submit"],
    "dependsOn": "CANDIDATE-ORDERS-001",
    "confidence": "high",
    "source": "stateHints"
  }
]
```

| 字段 | 说明 |
|------|------|
| `type` | `resource-lifecycle` / `state-transition` / `cross-module` / `key-transaction` / `auth-context` |
| `confidence` | `high`（双重验证）/ `medium`（仅源码归纳）/ `low`（推测性） |
| `source` | 识别来源说明 |

### 节点字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `level` | ✅ | 菜单层级，从 1 开始 |
| `label` | ✅ | 菜单文案（从侧栏/导航栏源码提取，不得猜测） |
| `route` | 条件 | 该菜单对应的前端路由 path（有子菜单的一级节点为 null） |
| `icon` | 推荐 | 菜单 icon 类名 |
| `expandable` | 推荐 | 是否有子菜单可展开（sub-menu） |
| `requiresAuth` | 条件 | 是否需要登录 |
| `children[]` | 条件 | 子菜单节点（结构同父节点） |
| `features[]` | 推荐 | 该页面上的功能操作入口列表 |
| `detail` | 推荐 | 同 pageEntryHints.detail 结构，弹窗/表单/表格 |

### features[] 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `label` | ✅ | 操作按钮/入口的文本 |
| `type` | ✅ | `create` / `edit` / `delete` / `export` / `view` / `state-transition` / `other` |
| `trigger` | ✅ | 触发方式：`toolbar-button`（顶部工具栏）/ `row-action`（行操作）/ `inline-button`（页内按钮）/ `menu-item`（更多操作下拉） |
| `evidence` | 推荐 | 源码文件名 + 行号/位置 |

### 导航路径生成规则

生成 UI 用例的菜单导航步骤时，按以下规则拼接路径：

```text
单层级（无子菜单）: 仪表盘 → click_menu("仪表盘")
多层级（有子菜单）: 资产管理 > 订单管理 → click_menu("资产管理") → click_menu("订单管理")
```

执行器中的 `click_menu` 会自动按层级逐级展开侧栏菜单。

### 提取来源

从以下位置提取导航树：

| 框架 | 布局组件 | 关键元素 |
|------|----------|----------|
| Vue + Element Plus | `Layout.vue` / `Sidebar.vue` | `<el-menu>` / `<el-sub-menu>` / `<el-menu-item>` |
| Vue + Ant Design | `BasicLayout.vue` | `<a-menu>` / `<a-sub-menu>` / `<a-menu-item>` |
| React + Ant Design | `BasicLayout.tsx` | `<Menu>` / `<SubMenu>` / `<Menu.Item>` |
| 自定义布局 | 项目侧栏组件 | 含 `.sidebar` / `.nav` / `.menu` 的元素 |

**所有 label 和菜单文案必须从源码中提取，不得猜测。**

### detail 字段说明

| 字段 | 必填 | 说明 |
|------|------|------|
| `detail.createForm` | 条件 | 该页面的创建/新增表单（dialog/drawer/inline-form），存在则必填 |
| `detail.createForm.type` | ✅ | `dialog` / `drawer` / `inline-form` |
| `detail.createForm.dialogTitle` | 条件 | type 为 dialog/drawer 时必填，弹窗标题文本 |
| `detail.createForm.fields[]` | ✅ | 表单字段列表 |
| `detail.createForm.fields[].label` | ✅ | 字段标签文本（从组件 template 提取） |
| `detail.createForm.fields[].selector` | ✅ | 定位线索（`placeholder=xxx` / `label=xxx`） |
| `detail.createForm.fields[].required` | ✅ | 是否必填 |
| `detail.createForm.fields[].type` | ✅ | `text` / `number` / `select` / `textarea` / `date` / `checkbox` / `radio` / `upload` |
| `detail.createForm.buttons[]` | ✅ | 操作按钮，含 `label` + `type`（submit/cancel/reset） |
| `detail.listTable` | 推荐 | 列表/表格结构 |
| `detail.listTable.columns[]` | 推荐 | 表格列名列表 |
| `detail.listTable.rowActions[]` | 推荐 | 行内操作按钮文案 |
| `detail.listTable.toolbarActions[]` | 推荐 | 工具栏按钮文案 |
| `detail.listTable.pagination` | 推荐 | 是否分页 |
| `detail.tabs[]` | 条件 | Tab 页签列表（页面存在时必填） |

### selector 定位规范

弹窗内字段使用 `dialog:弹窗标题|定位线索` 格式；页面级元素直接使用定位线索：

- `placeholder=xxx`：placeholder 属性匹配
- `label=xxx`：label/aria-label 匹配
- `testid=xxx`：data-testid 属性
- `文本内容`：兜底文本匹配

**所有 label、selector、dialogTitle 必须从源码中提取，不得猜测。**

## 与下游产物的关系

```
project-analysis.json
  ├─ mainFlowCandidates  ──→  api-cases mainFlowInventory（确认/扩展/排除）
  ├─ stateHints            ──→  api-cases 状态流转类主流程
  ├─ navigationTree        ──→  ui-cases 完整菜单导航路径（层级 + 路由 + 功能入口）
  ├─ pageEntryHints        ──→  ui-cases 菜单入口 + 逐页 DOM 拆解（detail）
  ├─ chainHints            ──→  flowChains 链路线索
  └─ crossModuleRefs       ──→  跨模块主流程
```
