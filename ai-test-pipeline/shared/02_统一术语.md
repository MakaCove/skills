# 统一术语

所有技能和产物中一致使用以下术语。完整 Schema 见 [01_目录.md](01_目录.md)。

## 编码规则

| 类型 | 格式 | 示例 |
|------|------|------|
| 主流程 | `FLOW-{MODULE}-{序号}` | `FLOW-ORDERS-001` |
| API 用例 | `TC-API-{MODULE}-{序号}` | `TC-API-ORDERS-001` |
| UI 用例 | `TC-UI-{MODULE}-{序号}` | `TC-UI-ORDERS-001` |

## trace 链路字段

所有用例统一使用 `trace` 对象：

| 字段 | 说明 |
|------|------|
| `trace.flowRefs` | 主流程 id 数组（`FLOW-*`） |
| `trace.dependsOn` | 上游用例 id 数组 |
| `trace.produces` | 本用例产出的变量名数组 |
| `trace.consumes` | 本用例消费的变量名数组 |

## 覆盖与验收

| 术语 | 定义 |
|------|------|
| `mainFlowCoveragePercent` | 主流程覆盖率，验收目标 **100%** |
| `orphanCases` | 无 `trace.flowRefs` 的用例数，应为 **0** |
| `scanLimitations` | project-analysis 中声明的本阶段未覆盖项 |

## 禁止字段

以下字段不允许出现在用例中：

- `dependsOnCases`
- 根级 `consumes` / `produces`
- `flowRef`、`featureRef`、`featureRefs`
- `contractRef`、`scenarioRef`

出现时将由校验器或执行器直接报错。
